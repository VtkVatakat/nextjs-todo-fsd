# Fullstack Todo List — Next.js App Router + Feature-Sliced Design (FSD)

Полноценное CRUD-приложение для управления задачами с серверными API-маршрутами (Route Handlers), двухуровневой валидацией данных и кэшированием запросов. Проект построен по архитектурной методологии **Feature-Sliced Design (FSD)**.

## Основной функционал
- **Полный CRUD:** создание, просмотр, редактирование текста («Изменить»), переключение статуса выполнения и удаление задач.
- **Серверный API на Next.js:** обработка HTTP-запросов (`GET`, `POST`, `PATCH`, `DELETE`) через App Router Route Handlers (`/api/todos` и `/api/todos/[id]`).
- **Валидация на клиенте и сервере:** проверка входящих данных через **Zod** в формах и в серверных обработчиках перед записью в базу.
- **Фильтрация списка:** мгновенная фильтрация задач («Все», «Активные», «Выполненные») через Redux Slice без лишних сетевых запросов.

## Стек технологий
- **Next.js 16 (App Router)** — клиентская часть и серверные Route Handlers
- **TypeScript 6** — строгая типизация и вывод типов из Zod-схем (`z.infer`)
- **Tailwind CSS v4** — адаптивная верстка интерфейса
- **Redux Toolkit (RTK Query + Slice)** — кэширование серверных данных, автоматическая инвалидация тегов (`providesTags` / `invalidatesTags`) и управление состоянием фильтров
- **Zod** — схемная валидация DTO и пользовательского ввода
- **Node.js `fs/promises` (`db.json`)** — локальное файловое хранилище (с поддержкой `/tmp` для serverless-окружения Vercel)

## Архитектура проекта (FSD)
```text
src/
├── app/                   # Роутинг Next.js, API Route Handlers, Redux Store и Provider
├── views/                 # Страницы приложения (переименовано из pages для совместимости с App Router)
├── widgets/               # Самостоятельные композиционные блоки интерфейса (TodoBoard)
├── features/              # Пользовательские действия (add-todo, todo-actions, filter-todos)
├── entities/              # Бизнес-сущность задачи (модель Zod, RTK Query эндпоинты, карточка TodoItem)
└── shared/                # Переиспользуемый код (базовый API-клиент, работа с файловой системой)
```

## Локальный запуск
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
3. Откройте [http://localhost:3000](http://localhost:3000) в браузере.
